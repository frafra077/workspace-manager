Novità

WorkSpace Manager 2.0.5

  • Tab Avanzate per Finder: Ora puoi aprire più cartelle del workspace in un’unica finestra Finder usando le schede.
  • Gruppi di Finestre Finder: Puoi decidere quali cartelle aprire insieme nella stessa finestra e quali aprire in una finestra separata.
  • Demo Pro per Finder Avanzato: Gli utenti Free possono provare la funzione con una demo limitata. Terminata la demo, le cartelle continueranno ad aprirsi normalmente in finestre separate.
  • Avviso Pro più Chiaro: Quando la demo termina, WorkSpace Manager spiega perché le cartelle vengono aperte separatamente e invita a passare a Pro per sbloccare il flusso avanzato.
  • Permessi Accessibilità: L’app ora controlla se il permesso è già attivo e mostra l’avviso solo quando serve davvero.
  • Correzioni Finder: Risolti i problemi che aprivano le cartelle in finestre separate anche con le tab abilitate e che potevano duplicare la prima cartella.
Aggiornamento precedente

WorkSpace Manager 2.0.4

  • Nuovo Motore di Aggiornamento: Sistema di update più rapido, sicuro e completamente automatico.
  • Compatibilità macOS Sonoma: Ripristinato il pieno supporto per macOS 14.
  • Controlli Avanzati: Verifica manuale degli aggiornamenti direttamente dalla tab Info nelle Impostazioni.
  • Avvio Intelligente: Controllo automatico delle novità all’apertura dell’app, senza interrompere il lavoro.
  • Rifiniture UI: Interfaccia delle impostazioni ottimizzata per una navigazione più fluida.
