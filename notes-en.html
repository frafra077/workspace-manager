What's New

WorkSpace Manager 2.0.8

  • Native Menu Follows App Language: The macOS menu bar now reflects the language chosen in the app settings — not just the system language — including entries automatically injected by macOS.
  • Multiple Terminals per Workspace: The Terminal & Commands section now supports multiple folders and commands per workspace, all launched simultaneously when the workspace opens.
  • Smarter Finder Group Reopening: The "Reopen Group" command now closes the group before reopening it, preventing duplicate windows.
  • Help Menu Linked to Official Website: The WorkSpace Help menu item now points directly to the app's official website.
  • French Release Notes for Sparkle: French update notes added to the Sparkle feed, alongside Italian and English.

WorkSpace Manager 2.0.7

  • New Liquid Glass Design: Settings and selection tabs have been redesigned with native materials, translucency, and a more spacious modern look.
  • Animated Onboarding: A new Apple-style welcome animation makes the first launch smoother and more premium.
  • Improved Finder Controls: Folder ordering is more visible, the group button is easier to read, and interactions feel more responsive.
  • Quick Reopen: A new popup lets you quickly reopen folders and related workspaces closed by mistake.
  • French Language: Full French localization support has been added.
  • Numeric Badges & Legend: Apps, Websites, and Files now show configured item counts, with a clearer symbol legend.
