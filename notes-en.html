What's New

WorkSpace Manager 2.0.5

  • Advanced Finder Tabs: You can now open multiple workspace folders in a single Finder window using tabs.
  • Finder Window Groups: Choose which folders open together in the same Finder window and which ones open in a separate window.
  • Pro Demo for Advanced Finder: Free users can try the feature with a limited demo. After the demo ends, folders will still open normally in separate Finder windows.
  • Clearer Pro Notice: When the demo ends, WorkSpace Manager explains why folders are opening separately and invites users to upgrade to Pro for the advanced workflow.
  • Accessibility Permission Flow: The app now checks whether Accessibility permission is already enabled and only shows the notice when it is actually needed.
  • Finder Fixes: Fixed issues where folders could open in separate windows even when tabs were enabled, including a case where the first folder could be duplicated.
